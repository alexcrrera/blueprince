# blueprince

## Programmation objet en Python - S1-25

This is the repository for the BluePrince2D project, which aims to create a simplified 2D version of the BluePrince game. You will find the source code, assets, and documentation needed to build and run the game.

## Installation

Clown the repo:

git clone <https://github.com/alexcrrera/blueprince>
cd <blueprince>



To install the necessary dependencies, run the following command:

pip install -r requirements.txt

## Usage
To run the game, execute the following command:
python main.py



# Game Controls

## Movement / Orientation - QWERTY and AZERTY supported
| Key | Action |
|------|--------|
| **W-Z** | Face **North** |
| **A-Q** | Face **West** |
| **S** | Face **South** |
| **D** | Face **East** |

---

## Interaction
| Key | Action |
|------|--------|
| **Space** | - Open a door<br>- Enter an existing discovered room<br>- Generate random rooms if the tile is empty |
| **Enter** | Confirm the selected room (during room selection) |
| **F** | Interact with an item (pick up / use) |

---

## Random Room Selection
| Key | Action |
|------|--------|
| **←** | Move the selection cursor left |
| **→** | Move the selection cursor right |

---

## Audio
| Key | Action |
|------|--------|
| **M** | Toggle music on/off |

---

## Quit
| Action |
|--------|
| Close the game window |
